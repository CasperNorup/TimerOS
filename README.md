# TimerOS

TimerOS is a planned Windows study timer that runs offline. Choose a focus routine, start it, and keep working with a small, click-through timer at the bottom of the screen. Customizable screen alerts signal focus and break transitions. Sound is off by default.

The planned timer modes include Pomodoro, fixed focus and break intervals, a countdown, a stopwatch, custom sequences, and Flowtime.
